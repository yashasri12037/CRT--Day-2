## 💻 Problems Solved

### 1. Count Digits in a Number
Calculated the total number of digits in a given integer using loops and mathematical operations.

**Concepts:** Loops, integer division, and counting.

### 2. Missing Number
Found the missing number in a sequence of numbers by exploring different logical approaches.

**Concepts:** Arrays, arithmetic operations, and logical reasoning.

### 3. Palindrome Number
Checked whether a number reads the same forward and backward by reversing the number and comparing it with the original.

**Concepts:** Loops, number reversal, and conditional statements.

### 4. Sum of Digits of a Number
Calculated the sum of all digits in a given number using mathematical operations and iteration.

**Concepts:** Modulus operator, integer division, and loops.

### 5. Majority Element
Identified the element that appears more than `n // 2` times in a list. Explored different approaches to solving the problem.

**Concepts:** Lists, element frequency, and problem-solving techniques.

### 6. New Year and Hurry
Calculated the maximum number of problems that could be solved within the available contest time.

**Concepts:** Loops, conditions, time calculations, and logical reasoning.
